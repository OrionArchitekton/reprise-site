# reprise-site

Vite/React microsite for the `Reprise` project page at
`https://www.danmercede.com/works/reprise/`.

## Role

This repo owns the marketing/presentation surface for `Reprise` (a reuse-first
gateway for generative media, in front of Backblaze B2, built for the Backblaze
Generative Media Hackathon 2026): layout, copy, metadata, static assets, and
Vercel cache config. The source project owns the Python gateway, the Genblaze
pipeline integration, the Object-Lock ledger, the labeled evaluation
(`eval/report.md`, regenerated by `tools/run_eval.py`), and tests.

## Source Of Truth

- Product repo: github.com/OrionArchitekton/reprise
- Site copy: `constants.ts` (`PRODUCT_DATA`)
- Metadata: `index.html`
- Cache headers: `vercel.json`

## Local Development

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Build And Deploy

- `vite.config.ts` sets `base: '/works/reprise/'` so emitted asset URLs
  resolve under the hub path.
- The danmercede.com hub (`danmercede-com` repo, `vercel.json`) rewrites
  `/works/reprise/` to this project's Vercel deployment,
  `reprise-site.vercel.app`.
- `vite-plugin-bodybake.ts` bakes a static, crawlable HTML body from
  `PRODUCT_DATA` into `#root` at build time, for answer-engine crawlers that
  do not run JavaScript. React replaces it on mount. The build fails if the
  baked body lacks an `<h1>` or `<p>`, or if the `#root` anchor is missing.

## Boundaries

Keep claims grounded in the source project README, `eval/report.md`, and
verified behavior. The routing counts in `constants.ts` are that report's
numbers; re-derive them from the report rather than hand-editing them. No
hackathon placement is claimed; never state one. Do not change the gateway
from this repo.
